# first-time
This project is an image classification program that uses a Convolution Neural Network (CNN) to train a model and predict the class of new images.

Technology:
Phyton
Tensorflow / Keras
OpenCV
Pillow
Matplotlib

functionality:
Loads images from a dataset
Trains a CNN image classification model
Automatically supports binary or multiple classes
Evalutates the model's accuracy
Saves the trained model
Loads the trained model to classify new images
Displays the image and its predicted class
